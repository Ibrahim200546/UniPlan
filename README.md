# UniPlan

Нативный Android-органайзер студента: Java, XML, Room и Firebase Authentication. Автор учебной работы — **Тәңірберген Ибраһим**, группа **АЖҚ-321**.

Версия **1.1.0** включает задания с поиском, фильтрами и отменой удаления, недельное расписание, заметки с TXT-экспортом, казахский и русский интерфейсы. Цвета фона, блоков и акцента, HEX и радиус скругления настраиваются отдельно для светлой и тёмной темы.

В **UniPlan Demo** первый локальный профиль — **Ибраһим / АЖҚ-321**. При первом входе ему добавляется предоставленное пользователем расписание из **23 занятий**; повторный вход не создаёт дублей, прежние данные сохраняются. Второй профиль позволяет проверить разделение владельцев. Внешние ссылки расписания сохранены как пользовательские данные; их доступность не подтверждена.

Для запуска откройте корень проекта в Android Studio, выберите Gradle JDK **17 или 21**, установите Android SDK **35** и выберите вариант **demoDebug**. Минимальная версия устройства — Android 7.0 / API 24. Подробные команды и инструкции для Windows находятся в [README_RU.md](README_RU.md).

Firebase-вариант содержит реализацию регистрации, входа и восстановления пароля, но **пользовательский Firebase-проект не настроен**. Он требует собственного `app/src/firebase/google-services.json`. Учебные записи остаются локальными; облачной синхронизации нет.
