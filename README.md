# UniPlan 1.2.0

Android-органайзер студента: Java, XML, Room и Supabase. Автор — **Тәңірберген Ибраһим**, группа **АЖҚ-321**.

Основной вариант приложения — **supabaseDebug** ('kz.uniplan.app'). Он поддерживает вход и регистрацию по email, подтверждение почты, восстановление пароля через PKCE, зашифрованную сессию и обновление токенов. Учебные записи доступны офлайн; кнопка **Профиль → Синхронизировать** сохраняет профиль, предметы, задания, занятия и заметки в аккаунте. При конфликте двух устройств приложение предлагает выбрать версию и подтверждает замену.

Сохранены русский и казахский интерфейсы, поиск и фильтры заданий, отмена удаления, недельное расписание, TXT-экспорт заметок и настройка оформления. **demoDebug** остаётся отдельной локальной демонстрацией с персональным расписанием из 23 занятий; **firebase** — прежний совместимый вариант. Они не публикуются как основной APK.

## Запуск

Установите **JDK 17**, Android SDK **35**, Build-Tools **35.0.0**. Откройте проект в Android Studio и выберите **supabaseDebug**. Минимальная версия устройства — Android 7.0 / API 24.

Публичная конфигурация проекта rrhuqwaytpeerirbnhlc находится в [config/supabase.properties](config/supabase.properties). Publishable key включается в APK; доступ к данным защищён Supabase Auth и RLS. Серверные ключи и пароли в приложение не добавляются.

    ./gradlew :app:testDemoDebugUnitTest :app:testSupabaseDebugUnitTest :app:lintSupabaseDebug :app:assembleSupabaseDebug
    npm ci --ignore-scripts
    npm test

На Windows используйте gradlew.bat. Для длинного пути проекта задайте -PtestTempDir=C:/Projects/uniplan-test-temp — короткий доступный каталог для тестового SQLite. Gradle 8.11.1 не запускается на JDK 25.
