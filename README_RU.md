# UniPlan 1.1.0 — учебный Android-проект

Автор учебной работы: **Тәңірберген Ибраһим**, группа **АЖҚ-321**, специальность «Ақпараттық жүйелер».

UniPlan помогает вести предметы, задания, недельное расписание и текстовые заметки. Интерфейс написан на Java и XML. Основной язык — казахский, есть русский язык и светлая, тёмная и системная темы. Данные хранятся локально в Room. Firebase Authentication отвечает за аккаунт, но **не синхронизирует учебные записи** между устройствами.

В версии **1.1.0** первый локальный демопрофиль — **Ибраһим, АЖҚ-321**. В него один раз добавляется предоставленное пользователем расписание из **23 занятий**. У занятия доступны номер пары, вид, отдельный преподаватель, аудитория и ссылка. В профиле также можно настроить цвета фона, блоков и акцента, ввести HEX и изменить скругление; светлая и тёмная палитры сохраняются независимо.

Фактические результаты сборки и проверки перечислены в [docs/TEST_REPORT.md](docs/TEST_REPORT.md). Наличие APK само по себе не означает, что пройдены все сценарии интерфейса или проверен настоящий Firebase.

## Быстрый запуск на Windows

1. Распакуйте `UniPlan_AndroidStudio.zip` в обычную рабочую папку, например `C:\Projects\UniPlan`.
2. В Android Studio выберите **Open** и папку `UniPlan`, содержащую `settings.gradle`. Создавать пустой шаблон не нужно.
3. В **Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK** выберите JDK **21** или **17**. Проект проверяется с JetBrains Runtime **21.0.11**. JDK 25, поставляемый с некоторыми новыми Android Studio, не подходит для закреплённого Gradle 8.11.1: выберите совместимый JDK отдельно.
4. В SDK Manager установите **Android SDK Platform 35**, **Build-Tools 35.0.0**, **Platform-Tools**. Android Studio создаст локальный `local.properties`; в архиве его намеренно нет.
5. Дождитесь Gradle Sync. Первая сборка требует интернет для библиотек Google Maven и Maven Central.
6. Откройте **Build Variants**, выберите **demoDebug**, затем запустите модуль `app` на Android 7.0/API 24 или новее.
7. Нажмите «Демоны ашу · Ибраһим · АЖҚ-321» / «Открыть демонстрацию · Ибраһим · АЖҚ-321». При первом входе этой версии профиль получает имя **Ибраһим**, группу **АЖҚ-321** и предоставленное расписание. Второй локальный профиль — Данияр — хранит свой набор записей и это расписание автоматически не получает.

**UniPlan Demo** имеет applicationId `kz.uniplan.app.demo`. **UniPlan** использует `kz.uniplan.app`. Это разные приложения с разными локальными хранилищами; можно установить оба. В демоверсии нет проверки email и пароля.

## Расписание Ибраһим

Откройте **«Сабақ кестесі / Расписание»** и выберите день. В предоставленном наборе семь предметов и 23 занятия:

| День | Занятий | Номера пар |
|---|---:|---|
| Понедельник | 6 | 1, 2, 3, 4, 5, 10 |
| Вторник | 4 | 1, 3, 4, 7 |
| Среда | 3 | 4, 8, 9 |
| Четверг | 6 | 1, 2, 3, 4, 5, 7 |
| Пятница | 3 | 2, 3, 4 |
| Суббота | 1 | 4 |

Названия предметов, время, вид занятия, преподаватели, аудитории и ссылки взяты из переданных пользователем данных. Например, понедельник начинается с двух лекций «3D Max-та моделдеу» в 08:30–09:20 и 09:25–10:15. Последняя, 23-я запись — субботняя лекция «JavaScript-те программалау», пара № 4, 11:25–12:15; адрес сохранён как «Талдыкорган қ, Жансугуров көшксі 226».

Нажмите карточку занятия, чтобы изменить её поля. Отдельный преподаватель занятия позволяет у одного предмета указать разных преподавателей лекции и лабораторной работы. Если это поле пустое, используется преподаватель предмета. Цвет самого предмета можно изменить в **«Профиль → Управление предметами»**: выбрать готовый цвет или ввести собственный HEX; этот цвет используется у соответствующих элементов расписания. На главной под приветствием показывается группа, а дата соответствует выбранному языку приложения.

Ссылка открывается внешним приложением по явному нажатию. У записи № 23 сохранён исходный адресный URL студенческого портала как **обычная ссылка**, а не ссылка Google Meet. Доступность этих внешних адресов и встреч не проверялась; наличие ссылки не означает подключение к университетской системе или подтверждённое участие во встрече.

Импорт применяется только к локальному владельцу `demo-1`. Он выполняется один раз и не заменяет всю базу: прежние задания, заметки, файлы и занятия сохраняются. Полностью совпадающие занятия не дублируются. Поэтому в обновлённой установке может быть **23 предоставленных занятия плюс прежние записи пользователя или старые примеры**. Повторный вход не размножает расписание и не возвращает занятия, которые пользователь затем удалил. Имя и группа меняются на Ибраһим / АЖҚ-321 только при первом таком импорте; последующие изменения профиля сохраняются.

Кнопка загрузки **примеров** в профиле остаётся отдельным явным действием. Её учебные примеры не являются предоставленным расписанием и могут добавить другие записи. Удалять данные приложения для перехода с версии 1.0 на 1.1 не нужно: добавлена миграция Room **1 → 2**.

## Настройка оформления

1. Откройте **«Профиль → Оформление»** (по-казахски — **«Профиль → Безендіру»**).
2. Выберите, какую палитру редактировать: **светлую** или **тёмную**. Этот переключатель выбирает набор для редактирования, а не активную тему приложения. Изменение одной палитры не заменяет другую.
3. Выберите готовую палитру «Лес», «Океан», «Песок» или «Лаванда» либо задайте **фон**, **цвет карточек** и **акцент**. Для точного цвета используйте шесть шестнадцатеричных цифр, например `#3D5C52` (`#` можно опустить). Альфа-канал не вводится. Неверный HEX отмечается у поля и блокирует применение.
4. Измените радиус скругления в пределах **0–32 dp** и оцените предпросмотр. Нулевой радиус даёт прямые углы.
5. Нажмите **«Применить и сохранить»**. Экран остаётся открытым; активное оформление обновляется без пересоздания Activity. Переключите саму тему в профиле и проверьте её отдельную палитру. Настройки сохраняются после закрытия приложения. **«Вернуть исходные цвета»** после подтверждения сбрасывает и сохраняет только выбранную палитру и её скругление.

Оформление — настройка устройства в пределах установленного варианта приложения, общая для его локальных аккаунтов. Вид заметок «список/сетка» по-прежнему сохраняется отдельно для каждого владельца. Цвет текста подбирается с учётом фона; акцент на отдельных поверхностях может корректироваться для читаемости. Палитры не изменяют учебные записи Room.

## Команды PowerShell

Выполняйте из папки проекта. Если системная Java слишком старая или слишком новая, задайте путь к **вашему** JDK 17/21:

```powershell
$env:JAVA_HOME = 'C:\Path\To\jdk-21'
.\gradlew.bat --version
.\gradlew.bat :app:assembleDemoDebug
.\gradlew.bat :app:testDemoDebugUnitTest
.\gradlew.bat :app:lintDemoDebug
.\gradlew.bat :app:connectedDemoDebugAndroidTest
```

Последняя команда требует работающего эмулятора или устройства с USB debugging. Проверка подключения: `adb devices`. Если SDK не в PATH, используйте полный путь к `platform-tools\adb.exe`.

Локальные тесты также включают Robolectric: при первом запуске скачивается его Android runtime. Это проверка Android-кода на JVM, а не запуск APK на телефоне. Для проекта с длинным путём на Windows удобнее использовать короткую папку, например `C:\Projects\UniPlan`.

Установка собранного APK:

```powershell
adb install -r .\app\build\outputs\apk\demo\debug\app-demo-debug.apk
adb shell am start -n kz.uniplan.app.demo/kz.uniplan.app.ui.auth.AuthActivity
```

На Linux: `chmod +x gradlew`, затем `./gradlew :app:assembleDemoDebug`. Проверка выполнения в этой работе проводилась на Windows; Linux-запуск отдельно не проверялся.

Готовые APK подписаны отладочным ключом. При собственной пересборке Android Studio может использовать другой debug-ключ; обновление установленного APK тогда потребует того же ключа либо удаления старой установки. Удаление приложения удаляет его локальные данные.

## Firebase

Конфигурация пользователя не предоставлена. Реализация настоящей регистрации, входа и восстановления находится в `app/src/firebase/`. Добавьте **свой** файл в `app/src/firebase/google-services.json` и включите Email/Password по [инструкции](docs/FIREBASE_SETUP_RU.md).

```powershell
.\gradlew.bat :app:assembleFirebaseDebug
```

Без файла Firebase-вариант тоже можно скомпилировать для проверки исходников; при попытке входа он покажет, что служба не настроена. Такой APK не доказывает работоспособность авторизации. Demo собирается и работает независимо от этого файла. Никогда не подставляйте случайные настройки чужого проекта.

## Данные и резервные копии

Room — основной источник заданий, предметов, занятий, профиля и сохранённых заметок. SharedPreferences хранит тему, язык и отдельные светлую/тёмную палитры оформления независимо от настройки вида заметок каждого владельца. Файловые копии не меняют запись Room до явного сохранения в редакторе.

Автоматическое резервное копирование Android отключено: `allowBackup=false`, `fullBackupContent=false`; для Android 12+ базы, настройки и файлы исключены и из облачного копирования, и из переноса устройства. Это не позволяет переносить авторизационные/локальные данные автоматически. Поведение отдельных производителей устройств может отличаться. **Переустановка или очистка данных удаляет локальные записи**; Firebase не восстанавливает их. TXT-экспорт сохраняет выбранную заметку, но не является резервной копией всей базы.

В Android Studio **Device Explorer** для debug-приложения:

- База: `/data/data/kz.uniplan.app.demo/databases/uniplan.db` (вместе с WAL/SHM при активной работе).
- Внутренние копии: `/data/data/kz.uniplan.app.demo/files/note_copies/<SHA-256 UID>/note_<id>.txt`.
- Собственные внешние копии: `/sdcard/Android/data/kz.uniplan.app.demo/files/note_copies/<SHA-256 UID>/note_<id>.txt`.
- Настройки: `/data/data/kz.uniplan.app.demo/shared_prefs/`.

Для Firebase-варианта замените пакет на `kz.uniplan.app`. Собственная внешняя папка **не является папкой Downloads**. Публичное место выбирается через системный «Сохранить как…». Широкие разрешения на файлы не нужны. Копии используют UTF-8.
