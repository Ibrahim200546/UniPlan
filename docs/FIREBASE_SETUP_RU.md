# Подключение Firebase Authentication к UniPlan

Настройка относится только к варианту **firebase**. Демоверсия `kz.uniplan.app.demo` использует два явно локальных профиля и не нуждается в Firebase. Рабочая пользовательская конфигурация при разработке не предоставлена; сквозная проверка реальной авторизации без неё невозможна.

В версии 1.1.0 первый демопрофиль — **Ибраһим / АЖҚ-321** — получает предоставленные пользователем 23 занятия локально и однократно. Это не Firebase-аккаунт и не синхронизация с университетским порталом. Вход в настоящий Firebase не импортирует этот персональный набор автоматически. Настройка фона, блоков, акцента и радиуса доступна в общих экранах обоих вариантов; параметры каждого установленного приложения хранятся отдельно.

1. Откройте [Firebase Console](https://console.firebase.google.com/), выберите свой проект или создайте проект для учебной работы. Не подключайте платные услуги. Для этого приложения Firestore, Realtime Database, Storage и Analytics не нужны.
2. Добавьте Android-приложение с **точным** package/applicationId `kz.uniplan.app`. Не добавляйте суффикс `.demo`. Имя приложения в консоли можно выбрать `UniPlan`.
3. Скачайте `google-services.json` и сохраните в **`app/src/firebase/google-services.json`**. Этот путь соответствует flavor. Файл не должен называться `google-services (1).json` или иметь скрытое дополнительное расширение `.txt`.
4. В Authentication → Sign-in method → Email/Password включите вход по email и паролю. Email link не требуется.
5. Проверьте Password policy. В приложении проверяется минимальная длина 6 символов и совпадение паролей; дополнительные требования проекта проверяет Firebase. При строгой политике SDK возвращает отказ, который показывается пользователю, а не превращается во вход.
6. В Android Studio выполните Sync Project, выберите `firebaseDebug`. Соберите `:app:assembleFirebaseDebug`, установите APK и создайте собственный тестовый аккаунт.

Google Services plugin подключается в `app/build.gradle` только при наличии файла. Генерация сервисных ресурсов для `demo` отключена. Если файла нет, Firebase-вариант остаётся компилируемым, но вход показывает понятную ошибку настройки. Не добавляйте поддельные API key, project ID или google app ID, чтобы скрыть отсутствие подключения.

Для этого варианта используются Firebase BoM **34.4.0**, Firebase Auth **24.0.1** и Google Services plugin **4.4.3**. Приложение не использует Admin SDK; приватный service-account JSON и серверные ключи в Android-проект добавлять нельзя.

## Проверка после подключения

1. Зарегистрируйте имя, email и пароль; проверьте ошибку при пустом имени, неправильном email, несовпадающих паролях и нарушении политики.
2. Убедитесь, что после регистрации открывается «Бүгін» и сохраняется сессия при закрытии приложения.
3. Создайте предмет, задание и заметку. Перезапустите приложение; записи должны остаться локально.
4. Выйдите и войдите вторым собственным тестовым аккаунтом. Первый набор данных недоступен; переход назад не должен открывать прошлую закрытую часть.
5. Восстановите пароль. Приложение показывает нейтральное сообщение, не раскрывающее существование аккаунта. Получение письма проверяется отдельно в вашем почтовом ящике.
6. Проверьте неверный пароль и отсутствие сети. Ошибка должна оставаться ошибкой. При уже сохранённой действующей сессии чтение локальных записей не требует сети.
7. Вернитесь в первый аккаунт и проверьте его прежние записи на том же устройстве.

Проверка `currentUser` выполняется через Firebase SDK и AuthStateListener. Поле `isLoggedIn` не используется. UID из Intent или пользовательского поля не является основанием для доступа к данным. Пароли не записываются в Room, настройки, файлы, SavedStateHandle и логи.

Имя/группа профиля редактируются локально в Room; email берётся из текущего аккаунта Firebase. Офлайн-приложение не гарантирует мгновенное обнаружение серверного отзыва сессии: SDK передаёт изменения авторизации, когда они известны ему. Синхронизации и серверной БД учебных данных нет.

Официальные источники: [подключение Firebase Android](https://firebase.google.com/docs/android/setup), [Email/Password Authentication](https://firebase.google.com/docs/auth/android/password-auth), [Android SDK release notes](https://firebase.google.com/support/release-notes/android).
